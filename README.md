# Gotham Cop — Remotion animation

Code-based noir 2.5D animation (1920×1080, 24 fps) built with [Remotion](https://github.com/remotion-dev/remotion).

- `storyboard/` — master storyboard (60 scenes) and script
- `public/narration.wav` — narration track (11:10)
- `src/` — Remotion compositions
- `.github/workflows/` — alignment + parallel rendering on GitHub Actions

Local: `npm ci && npm run studio`
